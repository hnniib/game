LINKUP — STATIC LEARNING WEBSITE
================================

CONTENTS
- index.html       Main website page
- css/style.css    Website styling and responsive layout
- js/app.js        Lessons, example filters, flashcards, and quiz logic
- prompts.txt      Prompt documentation for the assignment

HOW TO RUN LOCALLY
1. Extract the ZIP file.
2. Open the LinkUp-Project folder.
3. Double-click index.html, or open it in a browser.
4. An internet connection is recommended for the Google Fonts used in the design.

PERSONALISE BEFORE SUBMISSION
Open index.html and find the footer text:
[Course Name], [Your Name], and [Your Student ID].
Replace these placeholders with your real course name, full name, and student ID.

VERCEL DEPLOYMENT
1. Sign in to https://vercel.com.
2. Choose Add New -> Project.
3. Import a Git repository containing this project, or use Vercel's supported deployment workflow.
4. Set the project/root directory to the folder containing index.html.
5. Framework Preset: Other.
6. Build Command: leave empty.
7. Output Directory: leave as the project root (or use ./ if requested).
8. Deploy.
9. In Project Settings -> Domains, set or add your chosen *.vercel.app domain if it is available.

NOTES
- This is a static HTML/CSS/JavaScript project.
- No database or backend is required.
- All quiz scoring runs in the browser.
- Review all content and test the site before submitting.
- prompts.txt is a prompt log template for the prompts used to create this project. Add any further prompts used during later edits.
